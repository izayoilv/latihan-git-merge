## 🎯 Tujuan Project

Project ini dibuat sebagai latihan penggunaan **Git Merge** dalam kerja kelompok.

Setiap anggota mengerjakan bagian project pada branch masing-masing. Setiap branch kemudian melakukan merge terhadap branch sebelumnya secara bertahap hingga seluruh perubahan digabungkan ke branch utama.
